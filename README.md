# Data Engineering (DENG)

Welcome to the Data Engineering module at Hochschule Luzern.

This repository is the student-facing entry point for the module. It contains the weekly learning materials, practical exercises, project guidance, and selected references used during the semester.

## What is DENG?

Data engineering is the practice of designing and operating systems that make data available, trustworthy, and useful. In this module, you will learn to reason about data-engineering decisions and connect those decisions to practical implementations.

The focus is not on memorising one tool or following a tutorial mechanically. You will learn to explain why a particular architecture, ingestion pattern, storage choice, data model, or quality check is appropriate for a given situation.

## What you will learn

By the end of the module, you should be able to:

- describe the data lifecycle and the data-engineering lifecycle;
- identify sources, ingestion, storage, transformation, serving, and consumption in a data system;
- reason about batch and incremental processing choices;
- work with schemas, schema evolution, and common data formats;
- design and justify a cloud data pipeline;
- model data for analytical use;
- apply transformations, orchestration, and data-quality checks;
- communicate technical decisions, trade-offs, and limitations clearly.
