# Downloads before class

[Module homepage](../README.md)

Complete the released checklist for your week before travelling to class, using a reliable internet connection. Each file covers software, images, datasets, and a short readiness check. Learning activities and explanations remain in the weekly materials.

You do not need to understand the weekly tools to follow these preparation steps. You should not have to load a database, solve an exercise, or make architecture decisions as preparation.

| Week | Download checklist | Current status |
|---|---|---|
| 2 | [Week 2](week-02.md) | Database and local inspection preparation documented; Docker ingestion pending |

Preparation files for other weeks will be added when their materials are ready. Recheck your week's file when an update is announced. Do not discard downloaded images or files before the session.

If preparation fails, report the week, your operating system, the command, and its error through the course's usual support channel before class. Do not include passwords or `.env` contents.
